# Printable cases

| Folder | Fits | Status |
| --- | --- | --- |
| [`esp32-c6-devkitc-1/`](esp32-c6-devkitc-1/) | **Espressif ESP32-C6-DevKitC-1 only** | Printed and in use |

Each case is designed for one specific board. A case will not fit a different
board, even one with the same chip, because board size, USB port positions and
antennas differ.

If you design a case for another board, add it as a new folder named after the
board, with its STL files, a README covering printing and mounting, and the
source files.
